# Семейный бюджет

Веб-приложение для учёта семейных доходов и расходов. Работает полностью в браузере: без сервера, без регистрации. Данные сохраняются в `localStorage`.

## Структура проекта

```
├── index.html          # Приветственный лендинг
├── budget.html         # Калькулятор бюджета
├── Калькулятор.html    # Редирект на budget.html (старая ссылка)
├── css/
│   ├── common.css      # Темы, навигация, общие компоненты
│   ├── landing.css     # Стили главной страницы
│   └── budget.css      # Стили калькулятора
├── js/
│   ├── theme-init.js   # Ранняя установка темы
│   ├── theme.js        # Переключатель светлой / тёмной темы
│   ├── landing.js      # Предпросмотр бюджета на главной
│   └── budget.js       # Логика калькулятора
└── README.md
```

## Возможности

- **Главная страница** — краткое описание, шаги «как начать», предпросмотр сохранённого бюджета
- **Калькулятор** — добавление доходов и расходов, сводка, история с фильтрами и сортировкой
- **Финансовая нагрузка** — шкала доли расходов от доходов
- **Темы** — светлая и тёмная (кнопка в правом нижнем углу)
- **Локальное хранение** — ключи `familyBudget` (операции) и `familyBudgetTheme` (тема)

## Запуск

Откройте `index.html` в браузере двойным щелчком или через локальный сервер:

```bash
# Python
python -m http.server 8080

# Node.js (если установлен npx)
npx --yes serve .
```

Затем откройте в браузере: `http://localhost:8080`

## Технологии

HTML5, CSS3 (переменные для тем), JavaScript (ES5-совместимый синтаксис для простоты запуска без сборки).
